## Featured project

### [CogniStream AI](https://github.com/Sopannikam/CogniStream-AI)

A GitHub repository assistant: sign in, sync repositories, index source code, and ask questions with streamed answers and source-file citations.

- **Backend:** Java 21, Spring Boot, Spring AI, Spring Security OAuth2, Spring Data JPA.
- **Retrieval:** OpenAI embeddings and PostgreSQL with pgvector.
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, and TanStack Query.
- **Engineering:** encrypted GitHub tokens, repository ownership checks, indexing failure handling, SSE streaming tests, and GitHub Actions checks.

Adapted from the Chai aur Code RAG tutorial. Setup, architecture, source credit, and verification results are documented in the repository. Live GitHub OAuth and OpenAI integration still need a credential-backed walkthrough.
